# 📦 E-Commerce Pricing & Inventory Analysis

This project demonstrates how an online busines can collect, store, and analyze product pricing and inventory data.

**Source:** E-commerce website database
**Collected via:** Daily ETL process using SQL queries
**Stored in:** Databricks Delta Tables
**Access:** Data Analysts, Analysts Engineers, Data scientists, Data Engineers
**Goal:** Identify significant changes in product cost, selling price, and stock availability.

## 🔍 Tool Review

### Microsoft Excel

**Good for:** Quick analysis and reporting

**Strengths:**
- Familiar interface
- Pivot tables
- Easy chart creation

**Limitations:**
- Performance issues with large datasets
- Manual refresh processes

### SQL Server

**Good for:** Structured transactional data

**Strengths:**
- Powerful querying
- Reliable storage
- Supports automation

**Limitations:**
- Requires database administration
- Less flexible for unstructured data

### Databricks

**Good for:** Big-data analytics

**Strengths:**
- Handles massive datasets
- Spark-based processing
- Supports SQL and Python

**Limitations:**
- Requires advanced technical knowledge
- More expensive than simple database solutions

### Power BI

**Good for:** Dashboards and business reporting

**Strengths:**
- Interactive visualizations
- Easy sharing
- Strong integration with Microsoft products

**Limitations:**
- Dataset size limitations on some plans
- Requires specialized skills

## 📈 Example Analysis

The project identifies:

- Products with cost increases above 5%
- Brands with the largest price changes
- Inventory changes
- Changes in shipping costs
- Vendor-level pricing trends

## 📝 Reflection

For busines analyse of pricing and inventory monitoring, Databricks combined with SQL provides the most scalable solution. Excel is useful for performing fast, one-time analyses, while Power BI is ideal for presenting findings to business stakeholders.

    In a Ford Focus 2, data is generated by different sensors and processed inside multiple ECUs (Electronic Control Units). These ECUs  communicate through the CAN bus system, which acts as the internal network of the car.

    While the car is operating, sensors continuously send signals such as speed, RPM, fuel consumption, and temperature to the relevant ECUs. These units interpret and share the data across the CAN network.
