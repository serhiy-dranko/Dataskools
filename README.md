# Dataskools

This directory contains educational materials related to Dataskools training and practice.

The content is organized into two main categories:

Responses – practical tasks, exercises, and completed examples designed to reinforce key concepts and provide hands-on experience.

Quizzes – knowledge checks and assessment materials intended to evaluate understanding of the covered topics.

The purpose of this directory is to maintain a centralized collection of learning resources, making it easier to access, review, and track progress throughout the learning process.

Additional assignments, quizzes, and supporting materials may be added over time as the repository evolves.

## 🗺️ Program Roadmap

Here’s a high-level view of your learning journey over the next 28 weeks:

| Week Range     | Module Title                      | Key Focus                                                                 |
|----------------|-----------------------------------|---------------------------------------------------------------------------|
| Week 1–4       | 🧭 Introduction to Data Analytics | Foundations, career mindset, real-world use cases, tool setup             |
| Week 5–8       | 📊 Power BI                      | Dashboards, data visualization, AI visuals like Key Influencers           |
| Week 9–14      | 🗃️ SQL Fundamentals              | Querying databases, preparing data for analysis and ML                    |
| Week 15–20     | 🐍 Python & Machine Learning      | Data manipulation, ML concepts, skills test for track selection           |
| Week 21–24     | 💻 Big Data with Azure or Power BI| Track A: Azure + Big Data Tools<br>Track B: Power BI Advanced + Coursera  |

## 📚 Module Overview

<details>
<summary>🧭 Week 1–4: Introduction to Data Analytics</summary>

<br>

Start by exploring key concepts and real-world data use cases (movies, FIFA, Netflix). You'll get familiar with:
- Course structure and expectations  
- Communication tools: Slack, Zoom, Calendar  
- File handling, GitHub setup (your LMS)  
- Learning mindset, mock interviews, comfort zones
- Google spreadsheet and ETL processes
- Maths and Statistics  
- Why AI matters in today's data world  

</details>

<br>

<details>
<summary>📊 Week 5–8: Power BI</summary>

<br>

Learn to transform raw data into compelling dashboards using Power BI. You'll also explore:
- Data storytelling and business insights  
- Built-in AI tools like Key Influencers and Q&A Visual  
- Real business case studies for hands-on projects  

</details>

<br>

<details>
<summary>🗃️ Week 9–14: SQL Fundamentals</summary>

<br>

SQL is essential for querying, filtering, and joining data across systems. You'll focus on:
- Database basics and SQL syntax  
- Extracting and shaping data for analytics or machine learning  
- AI-ready data pipelines  

</details>

<br>

<details>
<summary>🐍 Week 15–20: Python & Machine Learning</summary>

<br>

Dive into automation, analysis, and model-building with Python. You’ll cover:
- Pandas, NumPy, and scikit-learn basics  
- Introduction to ML workflows: training, testing, predictions  
- A skills assessment to guide your specialization  

> 🧪 Based on your performance, you'll be guided into a suitable track:  
> - **Track A**: Azure Big Data (cloud, scale, ML pipelines)  
> - **Track B**: Power BI Advanced (enterprise reporting, large datasets)

</details>

<br>

<details>
<summary>💻 Week 21–24: Big Data with Azure or Power BI</summary>

<br>

**Track A – Big Data with Azure**  
- Azure Data Lake, Synapse, ML Studio  
- Managing and querying massive datasets  
- AI tools for cloud-based analytics  

**Track B – Power BI Advanced**  
- DAX functions, cloud data sources, advanced visuals  
- Real-world dashboards, KPI-driven storytelling  
- Optional: Coursera Power BI specialization access  

</details>
